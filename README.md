## 配置和流量怎么算：流量给多了，真正的瓶颈是内存

先算流量。一个 50–100 个产品页的普通外贸站，每页 2–3MB，日均 200 UV，一个月大概跑 50–80GB。图片多或者有视频，翻一倍到 160GB。RackNerd 最便宜的套餐给 3TB/月，是这个量级的四十倍左右，你基本不可能撞到流量上限。

真正的约束在内存和硬盘。

**20GB 硬盘**装完系统和 WordPress，剩下十几 G 放图片和备份。按每张产品图 300KB 算，空间够放几万张，但如果你习惯在服务器上留全站备份，两三个月就能把盘塞满。备份放本地或者对象存储，别跟网站抢同一块盘。

**1G 内存**跑 Nginx + PHP + MySQL 是能跑的，代价是得加 1–2G 的 swap，否则流量一冲就顶不住。这里有个具体的坑：RackNerd 下单页标注 Debian 11/12 建议至少 2G 内存，1G 套餐别选这两个系统，装 Ubuntu 或者更轻的发行版。

按站点类型分三档：

- **纯静态页、轻量 WordPress（插件少、无商城）**：1 核 1G 够用。装 Nginx 加缓存插件，1G 内存能撑住日均几百 UV。
- **WordPress + WooCommerce，产品数 1000 以内**：2 核 2G 起步。1G 内存跑 WooCommerce 会频繁 OOM，不是配置问题，是内存真的不够。生产环境更稳的口径是 4GB 内存，对应 4 GB 特价（$59.99/年），顺带把 PHP 8.0+、MySQL 8.0+ 或 MariaDB 10.6+ 一起配上。
- **产品数超 5000、有复杂筛选，或者 3–5 个小站共用一台**：4 核 4G 往上。RackNerd 的 6G 档给到 6 核 100GB SSD，跑容器和自建应用比 4G 档从容得多。

## 下单和开机后要做的几件事

购买流程不复杂：从特价页选套餐进购物车，选计费周期（年付或两年付）、操作系统、机房，用真实姓名地址和常用邮箱注册（账单和开通信息都发这个邮箱），结账。支付方式支持 PayPal、信用卡、支付宝（走 Stripe）、银联卡和 USDT/USDC，国内用户用支付宝最顺。付款后几分钟内开通，IP 和 root 密码会发到邮箱，也能在 ctrl 面板里看到。

开机后按顺序做这几步，能省掉后面一堆麻烦：

1. 先从国内 ping 一下新 IP，再用多节点工具测 22 端口通不通。有问题趁早开工单。
2. `passwd` 改掉初始 root 密码，或者直接在 ctrl 面板重置。
3. `apt update && apt upgrade -y` 把系统补丁打上。
4. 上传 SSH 公钥，在 `/etc/ssh/sshd_config` 里关掉密码登录，暴力破解基本就跟你无关了。
5. 用 `ufw` 只放行 22、80、443。ctrl 面板里还有一层网络防火墙，在流量到达服务器之前就过滤，VNC 控制台不受它影响，配错了还能从面板改回来。
6. 1G 内存的机器加 1–2G swap，这是跑 WordPress 的保命设置。
7. 把网站和数据库定期备份到别的地方。服务条款写明 RackNerd 不对数据完整性负责，这句话不是客套。

## 常见问题

**境外服务器要做备案吗？**
不用。只有中国大陆机房需要 ICP 备案，香港和美国机房都不需要。RackNerd 的机房全在美国、加拿大和欧洲，不涉及备案。面向欧盟客户要留意 GDPR，面向香港和亚太客户对应的是香港《个人资料（私隐）条例》，这些是数据合规问题，跟备案是两回事。

**CN2 GIA、9929、CMIN2 到底是什么？**
三个都是回国线路的代号。CN2 GIA 是电信的高端线路，9929 是联通优化线路，CMIN2 是移动优化线路，“三网优化”指三家运营商各走各的优化路径。这些线路影响的是中国大陆访问海外服务器的速度和质量，不影响海外买家访问。RackNerd 不主打这类线路。

**1G 内存到底够不够？**
跑轻量 WordPress 配 Nginx 和缓存插件够用，加 swap 更稳。跑 WooCommerce 不够，1G 会频繁 OOM，从 2G 起，生产环境建议 4G。

**流量用超了会怎样？**
RackNerd 5 档套餐的月流量从 3TB 到 20TB，普通外贸站很难用完。超额之后的处理方式（限速还是停机）在已核验的资料里没有明确说明，真担心这一点，下单前问一句客服比事后猜强。留 30%–50% 的余量是个稳妥习惯。

**续费会涨价吗？**
官方写明按原价续费，这也是它跟很多“首年特价、次年翻倍”商家的主要区别。下单时确认一下结账页显示的续费价格，以页面为准。

**能装 Windows 吗？**
可以，但要买 Windows VPS 产品线，2G 内存入门款 $27.59/月，没有年付特价。Linux 特价套餐里装不了 Windows。
